Dasar Komputer, Web, dan Keamanan Digital

1. Definisi dasar: Perbedaan perangkat seperti laptop, tablet, desktop, server, serta perangkat mobile dan game.
2. Data vs Informasi: Komputer mengolah data (input) menjadi informasi (output) yang bermakna.
3. Web dan Internet: Internet = jaringan global; Web = kumpulan halaman/situs yang diakses lewat browser; peran search engine dan social networks.
4. Input/Output/Penyimpanan: Contoh perangkat input (keyboard, pemindai), output (monitor, printer), dan media penyimpanan (HDD, SSD, flash, cloud).
5. Keamanan dan privasi: Risiko malware, praktik pencegahan, serta konsep green computing untuk mengurangi dampak lingkungan

Koneksi, Web, dan Layanan Internet

1. Sejarah singkat Internet: Berawal dari ARPANET; tujuan kolaborasi dan ketahanan jaringan.
2. Cara terhubung: Koneksi kabel vs nirkabel; modem, router, Wi‑Fi, seluler.
3. Struktur Web: URL, domain, alamat IP, server web, homepage, aplikasi web, dan penyimpanan awan.
4. Jenis situs web: Mesin pencari, jejaring sosial, media sharing, edukasi, berita, e‑commerce, wiki, dll.
5. Media digital: Penggunaan grafik, audio, video, animasi, dan VR di web.
6. Layanan lain: Email, mailing list, instant messaging, chat room, VoIP, FTP.
7. Netiquette: Aturan etika komunikasi online (sopan, hindari CAPS, tandai spoiler, dll).

Perangkat Komputer, Server, dan Kesehatan

1. Perangkat dan kategori: Rincian laptop, desktop, all‑in‑one, smartphone, kamera digital, e‑reader, wearable, konsol game, perangkat genggam.
2. Server dan virtualisasi: Jenis server (web, mail, database, file, backup, domain name, dll), server farm, dan konsep server virtual.
3. Terminal dan kios: Thin clients, ATM, kios swalayan sebagai terminal yang terhubung ke host/server.
4. Superkomputer dan cloud: Peran superkomputer; cloud computing sebagai layanan sumber daya lewat Internet.
5. Embedded systems dan IoT: Komputer tertanam di perangkat konsumen, otomasi rumah, kendaraan, robotika.
6. Port dan konektor: HDMI, USB (A/B/Micro), Ethernet, Thunderbolt, VGA, Lightning, dll.
7. Perlindungan perangkat keras: Kontrol akses fisik, alarm, pelacakan perangkat.
8. Kesehatan dan ergonomi: RSI, Computer Vision Syndrome, pencegahan ergonomis, dan tanda kecanduan teknologi.
