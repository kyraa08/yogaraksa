Pengantar Teknologi Informasi

1. Konsep Dasar Teknologi Informasi

1. Komputer adalah perangkat elektronik yang bekerja berdasarkan instruksi dalam memorinya.
2. Jenis komputer: laptop, tablet, desktop, all-in-one, server.
3. Perangkat mobile & game: smartphone, kamera digital, pemutar media portabel, e-book reader, wearable device, dan perangkat game.
4. Data vs Informasi: data adalah kumpulan item mentah (teks, angka, gambar, audio, video), sedangkan informasi adalah hasil olahan data yang bermakna bagi pengguna.


2. Internet dan Web Internet:

1. jaringan global yang menghubungkan jutaan bisnis, pemerintah, pendidikan, dan individu.
2. Evolusi: berawal dari ARPANET (1969) dengan tujuan berbagi informasi antar ilmuwan dan tetap berfungsi meski sebagian jaringan rusak.
3. World Wide Web (WWW): kumpulan dokumen elektronik (halaman web), situs web, dan server web.
4. Browser: aplikasi untuk mengakses dan menampilkan halaman web.
5. Search engine: perangkat lunak untuk menemukan situs, gambar, video, berita, dll.
6. Jenis website: mesin pencari, jejaring sosial, media sharing, blog, wiki, edukasi, bisnis, kesehatan, sains, hiburan, perbankan, retail, travel, dll.
7. Digital media di web: grafik, animasi, audio, video, virtual reality.


3. Perangkat Komputer dan Mobile

1. Laptop, tablet, desktop: komputer pribadi untuk aktivitas input, proses, output, dan penyimpanan.
2. Server: komputer khusus yang menyediakan layanan (aplikasi, database, email, web, backup, dll). Ada konsep virtualisasi server dan server farm.
3. Terminal: perangkat dengan kemampuan terbatas, misalnya ATM, POS, dan kios swalayan.
4. Superkomputer: tercepat dan terkuat, mampu memproses triliunan instruksi per detik.
5. Cloud computing: layanan dan sumber daya yang diakses melalui internet.
6. Embedded computer: komputer khusus dalam produk lain (mobil, elektronik rumah, robot industri, perangkat kantor).
7. Game devices: konsol, perangkat genggam, gamepad, joystick, roda, dance pad, motion-sensing controller.


4. Ports dan Koneksi

1. Port adalah titik sambungan perangkat periferal ke komputer.
2. Jenis port: USB (A/B/Micro/Mini), HDMI, VGA, DisplayPort, DVI, Thunderbolt, Ethernet, Lightning, headphone, microphone, dll.
3. Koneksi nirkabel: Wi-Fi, Bluetooth, NFC.


5. Keamanan Digital dan Privasi

1. Ancaman: virus, malware, pencurian data, privasi, kesehatan, dan lingkungan.
2. Green computing: mengurangi konsumsi listrik dan limbah dengan cara mendaur ulang, menggunakan perangkat hemat energi, memperpanjang umur komputer, dan membuang perangkat dengan benar.
3. Perlindungan perangkat keras: kontrol akses fisik, alarm, aplikasi pelacak, verifikasi identitas.
4. Masalah kesehatan: RSI (Repetitive Strain Injury), CVS (Computer Vision Syndrome), ergonomi, dan kecanduan teknologi.
