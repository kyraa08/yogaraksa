•Introducing Today's Technologies (Komputer, Perangkat, Web)

1. Perangkat: Perbedaan laptop, tablet, desktop, all‑in‑one, server; juga perangkat mobile seperti smartphone, kamera digital, pemutar media, e‑book reader, wearable, dan perangkat game.

2. Data & Informasi: Komputer menerima data (input), memprosesnya, lalu menghasilkan informasi (output); penyimpanan untuk penggunaan masa depan.

3. I/O & Penyimpanan: Opsi input (keyboard, pointer, suara, pemindai), output (monitor, printer, speaker), penyimpanan (HDD, SSD, flash, kartu memori, optik, cloud).

4. Web vs Internet: Internet = jaringan global; Web = kumpulan halaman situs yang disajikan oleh web server; browser untuk mengakses halaman; mesin pencari untuk menemukan konten.

5. Keamanan & Privasi: Risiko malware/virus, privasi, kesehatan, dan isu lingkungan; green computing (daur ulang, hemat energi, perpanjang umur perangkat).

6. Perangkat Lunak: Perbedaan sistem operasi (OS) dan aplikasi; instalasi dan menjalankan program.

7. Jaringan: Perbedaan teknologi kabel vs nirkabel; alasan penggunaan jaringan oleh individu dan bisnis.

•Connecting and Communicating Online (Internet, Websites, Media)

1. Sejarah & konsep Internet: Berasal dari ARPANET (1969); tujuan awal: berbagi informasi antar ilmuwan dan ketahanan jaringan.

2. Koneksi Internet: Metode kabel dan nirkabel; modem, wireless modem, broadband; perbedaan teknologi akses (DSL, kabel, satelit, seluler).

3.WWW & Browser: Web = dokumen elektronik (halaman web); situs = kumpulan halaman; server web mengirim halaman; browser menampilkan halaman; homepage dan tab browser.

4. Alamat IP & Domain: Alamat IP mengidentifikasi perangkat; nama domain memetakan alamat yang mudah diingat.

5. Pencarian efektif: Mesin pencari menemukan situs, gambar, video, berita; direktori subjek mengelompokkan situs.

6. Jenis situs web: Search engine, social networks, media sharing, blog, wiki, e‑commerce, edukasi, berita, layanan pemerintah, dsb.

7. Media digital di web: Multimedia (grafik, animasi, audio, video, VR) dan aplikasi web (disimpan di server; sering menggunakan cloud storage).

8. Layanan lain: Email, mailing list, instant messaging, chat room, diskusi online, VoIP, FTP (upload/download).

9. Netiquette: Aturan perilaku online: sopan, hindari flaming, jangan gunakan CAPS, tandai spoiler, baca FAQ, gunakan emotikon/akronim bila perlu.

•Computers and Mobile Devices (Perangkat, Server, Ports, Kesehatan)

1. Klasifikasi perangkat: Karakteristik laptop, tablet, desktop, all‑in‑one; server (dedicated types: web, mail, database, file, print, dll.); terminal (thin client, ATM, kios).

2. Virtualisasi & Server Farm: Virtualisasi memungkinkan satu server fisik menjalankan beberapa server virtual; server farm = banyak server di satu lokasi.

3. Superkomputer & Cloud: Superkomputer = performa tertinggi; cloud computing = sumber daya & layanan yang diakses via Internet (storage, apps, backups).

4. Perangkat mobile & game: Input alternatif (on‑screen keyboard, speech‑to‑text), kontrol game (gamepad, joystick, motion controllers), konsol & handheld.

5. Embedded computers: Komputer tertanam di perangkat konsumen, otomasi rumah, kendaraan, robotika, dll.

6. Ports & Connectors: Berbagai port populer (HDMI, DisplayPort, DVI, USB A/B, Micro/mini USB, Thunderbolt, Ethernet, VGA, audio, Lightning).

7. Perlindungan perangkat keras: Physical access control, alarm, security devices, tracking apps, identifikasi.

8. Kesehatan & Ergonomi: Repetitive Strain Injury (RSI), Computer Vision Syndrome (CVS), ergonomi tempat kerja (posisi lengan, sudut pandang layar, jarak pandang, kursi yang dapat disesuaikan), dan kecanduan teknologi.
