•Pengantar dan Literasi Digital Konsep utama

1. Literasi digital berarti mengikuti perubahan teknologi—memahami komputer, perangkat seluler, web, dan teknologi terkait.
2. Definisi komputer: “Computer adalah perangkat elektronik, beroperasi di bawah kendali instruksi yang disimpan dalam memorinya sendiri.” Inti: Komputer memproses data menjadi informasi yang berguna untuk pengambilan keputusan.

•Jenis Perangkat Komputasi dan Mobile

1. Perangkat utama: laptop, tablet, desktop (termasuk all‑in‑one), server, smartphone, kamera digital, pemutar media portabel, pembaca e‑book, wearable, dan perangkat game (konsol, handheld, controller).

•Perbedaan ringkas:

1. Laptop/tablet = portabel untuk pengguna individu; desktop/all‑in‑one = lebih kuat untuk penggunaan tetap; server = menyediakan layanan ke perangkat lain di jaringan.
2. Konsol game dan perangkat genggam dirancang khusus untuk permainan; kontroler meliputi gamepad, joystick, roda, dance pad, dan pengontrol sensor gerak.
3. Terminal dan kios: ATM, POS, kios swalayan, thin clients — terminal memiliki kemampuan pemrosesan terbatas dan bergantung pada host/server.

• Server, Virtualisasi, dan Superkomputer

1. Server: komputer yang menyediakan layanan ke perangkat lain di jaringan; jenis server meliputi web, mail, database, file, backup, dan domain name.
2. Virtualisasi: menjalankan beberapa sistem operasi di satu server fisik; server farm = kumpulan server untuk meningkatkan kinerja dan redundansi.
3. Superkomputer: komputer dengan kemampuan pemrosesan sangat tinggi, digunakan untuk penelitian ilmiah, simulasi cuaca, dan analisis data besar.

• Data, Informasi, Input/Output, dan Penyimpanan

1. Data vs Informasi: Data = fakta mentah; Informasi = data yang diproses menjadi makna.
2. Input/Output: Perangkat input (keyboard, mouse, scanner, kamera, mikrofon); perangkat output (monitor, printer, speaker).
3. Penyimpanan: Media penyimpanan primer (RAM) dan sekunder (HDD, SSD, flash drive, cloud storage).

• Sistem Operasi dan Aplikasi

1. Sistem Operasi (OS): perangkat lunak yang mengelola perangkat keras dan menyediakan antarmuka pengguna; contoh: Windows, macOS, Linux, Android, iOS.
2. Aplikasi: perangkat lunak yang menjalankan tugas tertentu; contoh: pengolah kata, browser web, aplikasi media sosial, game.

• Jaringan, Internet, dan Web

1. Jaringan: menghubungkan komputer dan perangkat untuk berbagi data dan sumber daya; jenis: LAN, WAN, MAN, PAN.
2. Internet: jaringan global yang menghubungkan jutaan komputer di seluruh dunia; menyediakan layanan seperti email, web, dan VoIP.
3. Web: kumpulan halaman dan situs yang diakses melalui browser; menggunakan protokol HTTP/HTTPS; URL = alamat unik untuk setiap halaman web.
